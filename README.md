# DSA Lab

A collection of data structures and algorithms implemented in Java, accompanied by written analysis documenting the reasoning behind each solution.

Rather than focusing solely on arriving at a correct answer, this repository emphasizes the complete problem-solving process—from understanding the requirements to evaluating tradeoffs and documenting why a particular solution was chosen.

---

## Problem-Solving Methodology

Each problem follows a consistent workflow:

1. Read the problem carefully.
2. Identify the given information and required output.
3. Analyze constraints and edge cases.
4. Brainstorm one or more possible approaches.
5. Select an appropriate data structure or algorithmic pattern.
6. Implement the solution in Java.
7. Validate the implementation with custom test cases.
8. Refactor or optimize when a better approach exists.
9. Document the reasoning behind the final solution.

Whenever possible, I compare multiple approaches to understand their tradeoffs rather than immediately adopting the first working solution.

---

## Documentation

Many problems are accompanied by Markdown notes or Jupyter notebooks that extend beyond the implementation itself.

These notes are intended to capture the reasoning behind the solution and typically explore questions such as:

* Why does this algorithm work?
* Why is this approach more efficient?
* What assumptions or constraints does it rely on?
* What alternative solutions exist?
* Under what circumstances would another approach be preferable?
* Which edge cases are important?

The objective is to build an understanding of the underlying concepts rather than simply recording a finished implementation.
